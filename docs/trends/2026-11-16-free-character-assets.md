# Free character asset source review

While the original pilot rendered, the scout reviewed two first-party sources for future expressive character animation. This used free public pages; no purchase, donation, paid research or production download was made. These are model-source leads, not streamer broadcasts, trend rankings or completed clips.

Kenney's Animated Characters Retro pack: https://kenney.nl/assets/animated-characters-retro (the older /animated-characters-3 URL resolves to this pack). The actual source page identifies the category as 3D, lists eight files and explicitly labels the pack Creative Commons CC0. Its page provides an ordinary free-download option. Actual model files, included license files, rig behavior and animation quality have not yet been inspected; source-page licensing is reviewed, but the asset is not activated for production.

Quaternius Ultimate Animated Character pack: https://quaternius.com/packs/ultimatedanimatedcharacter.html . The first-party page explicitly offers personal/commercial use, lists FBX, OBJ and Blend formats, and labels this specific pack CC0. The creator's homepage links to that exact spelling. License reference: https://quaternius.com/license.html ; the page provides a public download-folder route. No account login or purchase is established or required by this review. The downloaded payload/license and actual motion still need review before production use.

These sources may reduce future rigging work and support more expressive original scenes. They do not replace the finished-video quality check or authorize borrowed game IP, music, voices or another creator's script. The current Downward Beacon pilot remains entirely project-authored original geometry and has not been switched to these assets.
