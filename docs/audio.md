# Sound for Shorts

New posts use timed narration, a quiet original music bed, and light original transition sounds. Keep speech clear and let the last line land. The first cat Short was published before this change and remains as published; do not repost it to add sound.

## Reviewed sources

- Voice engine: [Piper](https://github.com/OHF-Voice/piper1-gpl), installed separately as `piper-tts==1.3.0` under GPL-3.0. `scripts/add_audio.py` is provided under GPL-3.0-or-later.
- Voice model: [en_US-ljspeech-high](https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/ljspeech/high/MODEL_CARD). The voice repository declares MIT licensing, and its model card identifies the [public-domain LJ Speech dataset](https://keithito.com/LJ-Speech-Dataset/). Model and configuration hashes are pinned in `config/audio.json`; changed downloads require a new review.
- Narration: original project scripts, synthesized locally. Do not represent the synthetic narrator as a real participant in the footage.
- Music: an original procedural composition generated by `scripts/add_audio.py`, using mathematical tones and a seeded arrangement. No music recording is sampled.
- Effects: original synthesized pops. No third-party sound recording is sampled.
- Stock source audio remains excluded unless independently reviewed.

## Render with sound

```sh
python3 -m venv work/audio-venv
work/audio-venv/bin/python -m pip install -r requirements-audio.txt
work/audio-venv/bin/python scripts/download_voice.py
work/audio-venv/bin/python scripts/render.py clips/coffee-loading-screen.json
```

`output/<clip-id>/video.mp4` is the finished file with AAC audio. `audio.json` records narration timing, voice provenance, and the rendered file hash. A pre-existing reviewed model can be selected with `--model /path/to/en_US-ljspeech-high.onnx`. The explicit `--silent` flag is only for an internal visual base; its output is not approved for new publication.

For an already-rendered clip, add sound while preserving its encoded video:

```sh
work/audio-venv/bin/python scripts/add_audio.py clips/coffee-loading-screen.json \
  --video media/2026-11-16/coffee-loading-screen.mp4 \
  --output media/2026-11-16-audio/coffee-loading-screen.mp4
```

Provide explicit `narration` text per caption when pronunciation or pace needs adjustment. Narration starts just after its caption appears and must end before the next caption. The mixer ducks music under speech and refuses overlapping narration or excessive speed-up. Target loudness is -16 LUFS, with headroom for encoding. Verify actual encoded levels, stereo AAC presence, complete decoding, and caption intervals before scheduling. Record `audio_version` in the publishing queue so analytics can distinguish the original silent post from later narrated clips.

## Change scheduled media

Refresh Metricool's queue first. Update only posts still marked `PENDING`, preserving their UUIDs, dates, audience, title, and other returned fields. Change the media URL and remove any outdated claim that the clip is silent. Do not create replacement posts or exceed the configured daily target. An update changes the numeric post ID; save its new value in private operational receipts. Confirm the resulting imported file contains audio and matches the inspected hash. A live video's soundtrack is not changed through this scheduling workflow.

## Motivational music

The owner requested high-energy motivational Shorts. config/licensed-music.json records the reviewed original Scott Buckley tracks Juggernaut and Ascension under CC BY 4.0. Both composer pages and the composer FAQ explicitly permit commercial audiovisual use with a credit in the YouTube description. Keep the exact attribution, source and license links, and modification note in each description. Remixes and unrelated commercial recordings are not included in this review.

Manifests may include audio.licensed_music with the reviewed file hash, excerpt start, rights record and credit. The renderer verifies the hash and refuses omitted rights/attribution, uses only that excerpt, fades it and ducks it under original narration. --music-file can reuse a downloaded reviewed track; otherwise the exact reviewed source is downloaded. Source audio remains excluded. Finished mixes still require decoding, caption timing, loudness and peak checks. The caption_style impact preset and manually reviewed portrait_crop framing support the motivational format; cropped framing must preserve the relevant action.
